## Small-model benchmark (`eval_models.py`)

`model_bench.jsonl` holds the 43 questions and gold for comparing candidate LLMs; `model_bench_calls.jsonl` holds the 57 prompts captured from the pipeline for them, committed so every model is replayed on the same prompts; `realchat_cases.json` holds the 27 end-to-end cases used for merge gates (and the three test documents). Method, fixed before any candidate was run:

- **FIR document.** The FIR test document is an ICDAR scan (no declared licence), so `realchat_cases.json` stores it as `doc_ref` and the captured prompt as `{{icdar_fir:<image>}}`; both are filled in at run time from `~/.cache/lawweb/fir_icdar/ocr.json`. `results/model_bench/blind_sheet.txt` quotes that text and is not committed.
- **Prompt replay.** The pipeline is run once with the production model and every prompt it sends to the LLM is recorded (`capture`). Each candidate then receives the identical prompts with production options (`num_ctx` 8192, the call's own temperature and output limit, `think=false` unless the model key ends in `-think`), two runs with different seeds. Retrieval is therefore the same for every model.
- **Strata.** A: grounded legal questions. B: no references retrieved (prompt built by the app's own no-retrieval builder). C: the retrieved context does not contain the answer. D: crime reports. E: document analysis (the scored answer is the final ANALYZE call). F: schema-constrained routing tie-breaks.
- **Gold.** Written from the statute text inside the captured prompts, without looking at any model's answer. `facts` are lists of acceptable phrasings (`re:` marks a regex); `cite` are sections that must be cited; `forbidden` are statements that must not appear; stratum B `facts` are well-known facts about the 2023 codes, since no context is supplied there.
- **Quality score** per answer (weights in `app/metrics/model_bench.py`): key-fact recall 0.25, citation recall 0.15, citation precision 0.20 (cited sections that exist and were in the supplied context; for documents, that exist in the index), supported claims 0.15 (rules-only `assess_grounding`, no LLM; strata A and C only, whose prompts carry the context format it reads), honesty 0.15 (B: nothing forbidden and no section cited from memory; C: abstains and nothing forbidden), format 0.10. Metrics that do not apply to an item are dropped and the rest renormalised. A model's score is the mean over items of the mean over runs.
- **Gates.** Fully on the GPU at `num_ctx` 8192 (`size_vram == size`); at most 2% failed calls, where a call that exceeds its role's production timeout (main 180 s, correction 60 s, prose 45 s, fast 15 s, tie-break 12 s), errors, returns nothing or is cut off counts as failed; at least 95% valid JSON on schema-constrained calls; reasoning or prompt text leaked into at most 2% of answers.
- **Decision rule.** Drop models failing a gate; among those within 0.03 of the best quality, pick the lowest median answer time. Differences from the baseline are reported with a paired bootstrap 95% interval over items.
- **Blind review.** `blind` writes a sheet of shuffled answers with model names replaced by codes for a fixed subset; scores (0–2 each for correct, complete, clear, safe) are entered against the codes and only then joined to the key with `unblind`.
